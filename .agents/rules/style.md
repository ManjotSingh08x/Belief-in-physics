# Style & Behavioral Guardrails

## Formatting & Tone
- Never use emojis anywhere in your responses, code, diffs, or documentation.
- Keep all explanations concise, direct, and straightforward. Avoid conversational filler or redundant recaps.

## Notebooks & Code Structure
- Do not add comments to Jupyter notebooks unless explicitly requested.
- Never use decorative banner comments (such as `# ===`, `# ---`, or verbose section dividers).
- Follow Ponytail principles: isolate computational, mathematical, and data logic in clean companion Python modules.
- In notebooks, only import and call top-level functions or UI widgets for a clean presentation.
